# Architecture Diagrams

This directory stores visual representations of the CarBroz system architecture.

## Storage Guidelines
- Diagrams should be maintained as code (e.g., Mermaid.js, PlantUML) or high-resolution exported images (SVG/PNG) alongside their source files (Draw.io/Excalidraw).
- **Core Diagrams**:
  - System Context
  - Clean Architecture Layers
  - Dynamic UI Engine Flow
  - Booking State Machine
  - Partner Dispatch Algorithms
