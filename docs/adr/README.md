# Architecture Decision Records (ADRs)

This directory stores Architecture Decision Records (ADRs) for the CarBroz Backend Platform.

## Purpose
ADRs capture significant architectural decisions along with their context and consequences. They provide historical context for why a specific library, pattern, or infrastructure component was chosen over alternatives.

## Naming & Numbering
- **Format**: `XXXX-short-title-of-decision.md`
- **Example**: `0001-use-bullmq-for-event-bus.md`, `0002-enforce-clean-architecture.md`.
- Numbering must be sequential and zero-padded.
