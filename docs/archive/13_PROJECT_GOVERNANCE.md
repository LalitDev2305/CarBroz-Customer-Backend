# 13 Project Governance

## Core Governance Rules
1. **Architecture Supremacy**: No code may be written that violates the established `00_ENGINEERING_STANDARDS.md`.
2. **ADR First**: Any change to infrastructure, patterns, or tools MUST be proposed via an Architecture Decision Record (ADR).
3. **Double Entry Accounting**: All financial ledgers must be append-only and strictly double-entry.
4. **Expand and Contract**: Zero-downtime database migrations are mandatory.
